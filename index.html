House Map & Issue Tracker

Sketch the house, name the rooms, and pin photos and issues where they belong.

This browser cannot work in a folder on disk, so projects are kept inside the browser, on this device only. Clearing the browser's site data deletes them: use File → Export project (.zip) to keep a copy, or to move a project to another device. Chrome or Edge on a computer keeps the plan and photos in a normal folder.

Each project is one folder:

plan.housemap.json        the plan
photos/unprocessed/       photos waiting to be placed
photos/processed/         placed photos, by floor and room

The house name and address above are used for the new project. An exported project brings its plan, photos and aerial picture; a plan file on its own brings no photos.

You will get an exterior sheet for the outline of the house, plus one sheet per floor. The browser will ask for permission to view and edit files in the folder you choose; the app needs both to save the plan and to file photos.
The exterior outline is not confirmed as true to size yet. Rooms drawn here are not resized when the outline is, so size the outline first.

House

What is known about the house as a whole. It is saved as you type, and goes into Export for AI.

Issues

Click an issue to read or change it in the side panel. To add one, open a floor, choose Issue and click the spot.

Issues

House standards

Rooms are drawn as the clear space inside them, so the app needs to know how thick the walls between them are and how wide the doors usually are. The suggested values are filled in; change any that differ in this house.

Round to the nearest 1/4 inch. Fractions are fine: 4 1/2. These are starting points: any one wall or door can be given its own size, and changing them later only affects what you draw afterwards.

Print or save as PDF

Choose what to include. The browser's print window opens next. To get a PDF file, choose “Save as PDF” as the printer there.

The exterior sheet prints the whole lot; each floor is fitted to its own rooms so the house fills the page. Anything turned off in the View menu is left out, and the numbered pins match the numbers in the report. The aerial picture is not printed.

Export for AI

Makes one zip file to give to an AI assistant, such as Claude or ChatGPT, so it can look over the house with you. It holds a brief in plain words, README-FIRST.md, that gives the house facts, your goals and the walkthrough checklist, and says where each issue is and what is above and below it; a small copy of each issue's photos; a picture of each floor; and the issue list as a table. The brief opens with a request you can paste in.

Nothing is sent anywhere by this app: the zip is saved to this computer, and you choose what to do with it. Company names and amounts on quotes are always in the brief. The house address is in it too, if one is filled in.

Round to the nearest 1/4 inch. Fractions are fine: 5 3/4.
